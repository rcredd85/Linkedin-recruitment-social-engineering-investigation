# Evidence analysis

| Evidence | What it supports | What it does not establish |
|---|---|---|
| Generic remote work solicitation | Broad recruiting pitch | A fraudulent job offer |
| Claim of recruiting affiliation | Sender made an affiliation claim | Verified employment or authorization |
| Request for phone number or resume | Contact information was solicited | Identity theft or data misuse |
| No job title or requisition in message | Details absent from observed message | Nonexistence of any vacancy |
| Similar surname on separate GitHub profile | Similarity in visible names | Shared identity, relationship, or wrongdoing |
| Recipient's affirmative reply | Initial engagement | Disclosure of sensitive information |

## Confidence
- High: screenshot-visible message wording and profile fields.
- Moderate: recipient's report that no information was shared; corroborate with full conversation export if needed.
- Low/unknown: authenticity of recruiter affiliation, motive, and downstream activity.

## Verification checklist
- [ ] Obtain exact position title and requisition ID
- [ ] Locate the posting independently on the employer's official site
- [ ] Verify recruiter's affiliation through an independently obtained corporate channel
- [ ] Preserve any follow-up messages with dates and context
- [ ] Reassess conclusions without publishing identifying details
